# T-Choob AI

این نسخه شامل:
- چت متنی با GPT-5.6 Luna
- گفت‌وگوهای چندگانه و localStorage
- حالت تاریک
- ارسال تصویر و فایل
- تحلیل فایل/تصویر در endpoint چت
- endpoint جدا برای تولید تصویر با GPT-Image-2

مدل‌های استفاده‌شده مطابق فهرست فعلی مدل‌های OpenAI تنظیم شده‌اند.

## Backend

در Vercel این متغیر را تنظیم کن:

OPENAI_API_KEY

برای فعال‌کردن تولید تصویر:

IMAGE_GENERATION_ENABLED=true

اگر فعلاً نمی‌خواهی تولید تصویر فعال باشد، متغیر دوم را اضافه نکن.

بعد از تغییر Environment Variables یک Deploy جدید انجام بده.

## Frontend

در `script.js` مقدار زیر را با آدرس واقعی Vercel عوض کن:

```js
const API_BASE_URL = "https://YOUR-VERCEL-PROJECT.vercel.app";
```

کلید API هرگز نباید داخل Frontend قرار بگیرد.

## فایل‌ها

فرانت‌اند فعلاً هر فایل را به صورت Data URL به بک‌اند می‌فرستد و سقف هر فایل ۱۰MB است. برای نسخه نهایی و فایل‌های بزرگ، بهتر است Object Storage جداگانه اضافه شود.

## ویدئو

endpoint ویدئو در این بسته عمداً فعال نشده و بعداً می‌توان آن را بر اساس API و مدل ویدئویی فعلی OpenAI به‌صورت جداگانه اضافه کرد.
